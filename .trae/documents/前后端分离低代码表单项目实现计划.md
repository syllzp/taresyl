# 前后端分离低代码表单项目实现计划

## 项目结构
```
taresyl/
├── frontend/          # Vue 3前端项目
├── backend/           # Django后端项目
└── README.md          # 项目说明
```

## 前端实现 (Vue 3 + v-form)
1. **初始化项目**
   - 使用 Vite 创建 Vue 3 项目
   - 安装必要依赖：v-form、axios 等

2. **核心功能**
   - 集成 v-form 低代码表单设计器
   - 实现表单配置的可视化编辑
   - 实现表单的实时预览功能
   - 实现表单配置的保存和加载

3. **技术栈**
   - Vue 3 + Vite
   - v-form (低代码表单库)
   - Axios (API 请求)

## 后端实现 (Django + DRF)
1. **初始化项目**
   - 创建 Django 项目
   - 安装 Django REST Framework

2. **核心功能**
   - 设计表单配置模型 (FormConfig)
   - 实现序列化器 (FormConfigSerializer)
   - 实现 ViewSet (FormConfigViewSet)
   - 配置 RESTful API 路由

3. **技术栈**
   - Django 4.x
   - Django REST Framework
   - SQLite (开发环境)

## 实现步骤
1. 创建项目目录结构
2. 初始化前端 Vue 3 项目
3. 初始化后端 Django 项目
4. 实现后端表单配置模型和 API
5. 实现前端表单设计器和渲染器
6. 集成前后端，实现数据交互
7. 测试完整功能

## API 设计
- `GET /api/form-configs/` - 获取所有表单配置
- `GET /api/form-configs/{id}/` - 获取单个表单配置
- `POST /api/form-configs/` - 创建表单配置
- `PUT /api/form-configs/{id}/` - 更新表单配置
- `DELETE /api/form-configs/{id}/` - 删除表单配置
